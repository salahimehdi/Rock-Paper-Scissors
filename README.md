# Rock, Paper, Scissors

A small, responsive browser game built with HTML, CSS, and vanilla JavaScript.

## Play locally

Open `index.html` in any modern browser. No installation or server required.

## How to play

Choose Rock, Paper, or Scissors. The computer randomly picks a move and the result and scores update automatically. Click **Reset scores** to start fresh.

## GitHub Pages

Upload the files to a GitHub repository, then open **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save.

## Background

Based on a first Python terminal game, adapted to JavaScript so it runs directly in a browser.
